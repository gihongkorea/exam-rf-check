① 이 브라우저에서 되는지 확인

    스캔이 '불가'로 나오면 (Chrome 실험 기능 켜기)
    1. 주소창에 chrome://flags/#enable-experimental-web-platform-features 입력
    2. Experimental Web Platform features → Enabled → 브라우저 재시작
    3. 안드로이드: 블루투스 ON, 위치(GPS) ON, Chrome에 '근처 기기'·위치 권한 허용
    4. 페이지는 https:// 또는 http://localhost로 열어야 합니다 (파일 직접 열기 X)
    5. 아이폰 Safari는 웹 블루투스를 지원하지 않습니다 → 시연 모드만 가능

    ⑤ 와이파이 · 핫스팟

    상태신호와이파이 이름대역주소(BSSID)
    와이파이도 같이 보려면 (안드로이드 Termux)
    1. F-Droid에서 Termux, Termux:API 설치 → Termux:API 앱에 위치 권한 허용, GPS 켜기
    2. Termux에서 pkg install python git termux-api
    3. git clone https://github.com/gihongkorea/exam-rf-check
    4. python exam-rf-check/python/exam_server_termux.py
    5. Chrome에서 http://localhost:8000 열기 (업데이트: cd exam-rf-check && git pull)

    웹 브라우저는 보안상 와이파이를 직접 스캔할 수 없어서, 폰 안의 Termux 서버가 목록을 대신 전달합니다.
